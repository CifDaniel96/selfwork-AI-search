# Aulab Segugio

Aulab Segugio è un assistente di ricerca web intelligente sviluppato durante la Specializzazione Agentic AI & Python di Aulab.

L'applicazione utilizza un workflow iterativo basato su AI per ottimizzare la richiesta dell'utente, effettuare ricerche sul web, sintetizzare le informazioni raccolte e individuare automaticamente nuovi aspetti da approfondire.

## Funzionamento

Il flusso principale dell'applicazione è:

```text
User Query
    ↓
Query Optimization
    ↓
Web Search
    ↓
Summarization
    ↓
Reflection
    ↓
Follow-up Query
    ↓
Nuovo ciclo di ricerca
    ↓
Final Answer
